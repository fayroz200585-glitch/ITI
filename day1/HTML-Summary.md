# HTML Summary

## What is HTML?
HTML stands for HyperText Markup Language.
It is the standard language used to create and structure web pages.

## What is HTML used for?
HTML is used to create the structure and content of a web page.
It helps us add headings, paragraphs, images, links, tables, forms, and other elements.


## Basic Structure of an HTML Page

Every HTML page usually contains these main parts:

<html>
The root element of the HTML document.

<head>
Contains information about the page, such as the title and metadata.

<body>

Contains all the visible content of the web page.


## Most Common HTML Tags

<h1> to <h6>
Used for headings. <h1> is the largest and most important heading.

<p>
Used to write paragraphs.

<a>
Used to create links.

<img>
Used to add images to a web page.

<div>
Used as a container to organize and group elements.

<br>
Used to make a line break.

<hr>
Used to add a horizontal line.

<ul>
Used to create an unordered list.

<ol>
Used to create an ordered list.

<li>
Used to create an item inside a list.

## Tables

<table>
Used to create a table.

<tr>
Used to create a table row.

<th>
Used to create a table header cell.

<td>
Used to create a table data cell.


## Forms

<form>
Used to create a form for collecting user information.

<input>
Used to create input fields.

<label>
Used to add a label for an input field.

<button>
Used to create a button.

<textarea>
Used to create a multi-line text input.


## Other Important Tags

<title>
Defines the title of the web page shown in the browser tab.

<meta>
Provides information about the HTML document.

<header>
Represents the header section of a page.

<footer>
Represents the footer section of a page.

<section>
Defines a section of a web page.

<!-- Comment -->
Used to write comments in HTML. Comments are not displayed on the web page.
